# at-ai-child-game

用 AI 编写的少儿教育类小游戏合集，共 **21 个游戏**（20 个教育游戏 + 1 个 three.js 3D 竞速游戏 `racing-3d`，后者未列入主页快捷目录）。每个游戏都是**零依赖的单 HTML 文件**，下载后双击即可在浏览器中离线游玩。

## 游戏

从仓库首页 `index.html` 可以点击进入各个游戏；也可以直接打开各游戏目录下的 HTML 文件。

## 🔈 语音播报不发声？

游戏使用浏览器内置的 Web Speech API 朗读中文。如果只听到音效、听不到语音，按顺序检查：

1. **确认浏览器**：推荐用 **Chrome** 或 **Edge** 打开（联网时会自动使用 Google/微软在线中文语音）。Safari 依赖 macOS 系统语音库。
2. **macOS 安装中文语音**（Safari 必须；系统自带语音更好听）：系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音 → 中文（简体）→ 下载"婷婷"等语音。
3. **游戏内检查**：点右上角 🔊 确认没有静音（静音时音效和语音一起关闭）。
4. 语音播报的文字内容都会同步显示在**字幕条**上，听不清也能看。

### 🏎️ 数字赛车（number-car）

开着赛车在伪 3D 赛道上飞驰！前方会出现携带数字号码牌的对手车（跑车 / 卡车 / 挖掘机 / 装载机），当对手与你并排时弹出数字输入挑战：

- **答对** → 加速超越对手，获得表扬
- **答错** → 语音播报正确数字并提示重试，直到答对为止（无惩罚，鼓励学习）

**教育目标**：0-9 数字认知、键盘数字键 / 触屏数字键盘练习

**玩法**：
1. 打开 `number-car/index.html`（双击即可，无需服务器）
2. 点击「开始比赛」
3. 对手车接近并排时，输入车尾号码牌上的数字（触屏设备自动显示数字键盘）——**输入即自动提交，无需按回车**
4. 答对超车继续前进，答错会告诉你正确数字，再输一次就行
5. 全程 1000 米，抵达终点获得奖牌（金 18 连对 / 银 12 / 铜 6）

**特性**：
- 伪 3D 透视赛道（OutRun 式投影）：S 形弯道、距离雾化、地平线辉光——速度感强且不刺眼
- 四种尾视图车型：低趴宽体跑车（全宽 LED 尾灯带 + 大尾翼 + 扩散器 + 铬双排气）、厢式卡车（导流罩 + 卷帘门 + 斜纹防撞梁）、挖掘机（履带底盘 + 两段大臂 + 闪爆警示灯）、装载机（人字胎纹 + ROPS 防滚架 + 铲斗连杆），车尾都有醒目的圆形号码牌
- 路边景深装饰：透视分布的松树、护栏柱、带悬垂电线的电线杆
- Web Speech API 中文语音播报：挑战弹出播报"对手的号码是 8，8！"（数字重复两遍），答错时同样重复播报正确数字
- Web Audio 引擎音效与提示音（可静音）
- 答题连击与奖牌结算

### ✈️ 数字飞机（number-plane）

驾驶战机在高空巡航！敌机（战斗机 / 轰炸机 / 直升机）迎面飞来，机身带着大数字。锁定目标后输入它的数字发射导弹：

- **答对** → 导弹沿弧线飞出击毁敌机，**你的战机会变大变强**（战力成长系统）
- **答错** → 语音播报正确数字并提示重试，直到答对为止（无惩罚）

**教育目标**：0-9 数字认知、键盘数字键 / 触屏数字键盘练习

**玩法**：
1. 打开 `number-plane/index.html`（双击即可，无需服务器）
2. 点击「开始任务」
3. 敌机被锁定（出现瞄准框）后，输入它机身号码牌上的数字（触屏设备自动显示数字键盘）——**输入即自动提交，无需按回车**
4. 答对发射导弹击毁敌机，主角战机变大一点（战力 +7%）
5. 击毁 15 架敌机完成任务，按最佳连对颁发金 / 银 / 铜牌

**特性**：
- 三种敌机造型：后掠翼战斗机、双引擎螺旋桨轰炸机、旋翼旋转的直升机
- 导弹抛物线弹道 + 尾烟 + 爆炸冲击环 + 白闪屏震
- 战力成长系统：每击毁一架战机变大（HUD 实时显示战力百分比）
- 旋转虚线锁定框 + 四角括号瞄准动画
- 视差云层 + 星空夜色背景
- Web Speech API 中文语音播报：锁定敌机播报"它身上的数字是 0，0！"（数字重复两遍），答错时同样重复播报
- Web Audio 引擎音效与提示音（可静音）

### 🎈 数字打气球（number-balloon）

彩色气球从夜空缓缓升起，每只都写着大数字。听语音喊出目标数字，把它戳破！

**教育目标**：0-9 数字认知（2-4 岁低幼，点击为主，支持键盘）

**玩法**：打开 `number-balloon/index.html` → 点「开始游戏」→ 听语音（如"戳数字 7！7，7！"，数字重复读）→ 点击写着 7 的气球爆炸得分；点错会告诉你"这是数字 3，找找 7，7 吧"。答对 10 题结算，按最佳连对颁发奖牌。

**特性**：语音字幕条提示、爆炸纸屑粒子、气球飘走自动补发、无惩罚重试、键盘 0-9（含小键盘）直接打气球、回车/空格快速开始或重开。

### 🚂 数字小火车（number-train）

车站月台停着乱序车厢，按 1 → 2 → 3 的顺序点击挂到火车头上，挂满整列呜呜开走——开出屏后还会调头开回月台再进下一站！

**教育目标**：数序概念 1-20（3-6 岁，点击为主，支持键盘）

**玩法**：打开 `number-train/index.html` → 点「发车！」→ 听语音提示先挂几号（如"先挂 1 号，1 号！"，数字重复读）→ 依次点击正确编号车厢（飞到车尾挂上），挂对后播报"接下来挂 5 号，5 号！"；点错车厢会抖动并重复播报要挂的数字。挂满后列车向左开出屏，调头（车头镜像朝右）鸣笛开回右侧月台，到站后进下一关。20 站递增（3 节 → 20 节，第 8 站起出现 10-20 号两位数车厢），通关结算（金 15 连挂 / 银 10 / 铜 5）。

**特性**：白天草原场景、烟囱冒烟粒子、两趟行程（出站 + 调头回站）、开走鸣笛音效、连挂奖牌、键盘直接挂车厢（两位数先按十位再按个位，如 1+5 = 15 号）、回车/空格快速开始或重开、第 20 站 20 节超长列车（两位数车厢用加宽数字牌）。

毛茸茸的小怪兽肚子饿啦！它说"我要吃 3 个苹果"，就从果树摘 3 个喂它，吃多会吐出来（不生气）。

**教育目标**：数量对应 2-6（3-6 岁，点击计数）

**玩法**：打开 `math-monster/index.html` → 点「开始游戏」→ 听目标数量 → 点击树上的苹果（抛物线飞进嘴里）；头顶气泡显示目标数，肚皮实时显示 n/m；吃满自动封嘴，多点会被温和吐出。8 关结算。

**特性**：大嘴开合动画、打嗝音效、计数气泡、无失败设计。

### 🐿️ 松鼠摘松果（squirrel-pinecone）

松鼠妈妈要囤松果过冬啦！听一听要摘几颗，点一点树上的松果掉进篮子，跟着数 1、2、3……

**教育目标**：按数取物 1-9（3-4 岁，数字 → 数量的逆向映射，基数概念）

**玩法**：打开 `squirrel-pinecone/index.html` → 点「开始摘松果」→ 听语音（如"摘 3 颗松果！3，3！"）→ 依次点击树上的松果，每颗落篮时实时报数；篮中数量徽标实时显示 n/目标。摘多了会提示"只要 3 颗，放回 1 颗"（隐含减法），点篮子放回多余松果；不多不少自动飞进树洞藏好。8 筐通关（数量 1-3 → 4-6 → 7-9 三档递进），结算显示一共帮松鼠藏了多少颗。

**特性**：夜晚森林场景（月亮/远山/篝火色草地）、树上松果微光呼吸提示、落篮抛物线动画、逐颗报数（数到最后一个数 = 总数的基数教学）、摘多放回的温和纠错、树洞藏果计数木牌、松鼠妈妈头顶目标气泡。

### ⚖️ 数字跷跷板（seesaw-compare）

跷跷板两边坐着数字小伙伴！从数小动物比多少，到看点点，再到直接比数字——点对重的一边，跷跷板咣当沉下去！

**教育目标**：比较多少 / 比较大小（3-5 岁，量的比较启蒙）

**玩法**：打开 `seesaw-compare/index.html` → 点「开始游戏」→ 听语音"哪边的小动物多？"→ 点动物更多（或数字更大）的一侧；答对跷跷板向重侧咣当沉下（弹簧动画 + 闷响音效）并播报"5 个比 3 个多！"；答错晃一晃，逐个数给你看。10 题三阶段递进：1-3 题看小动物数多少、4-6 题看点阵、7-10 题直接比数字（含两位数）。

**特性**：夜空星星背景、动物 emoji 队列（8 种随机）、跷跷板支点三角结构 + 板面旋转物理感、答对下沉弹簧动画、点阵模式彩色圆点、纯数字模式大数字牌、连对奖牌。

### 🧩 七巧板（tangram）

七块彩色拼板拼出小猫、房子、小船、火箭、小鱼、蜡烛、风车、天平、皇冠！点选拼板、旋转方向、放到轮廓影子附近自动吸附。

**教育目标**：图形空间拼组（4-8 岁，旋转 + 吸附操作）

**玩法**：打开 `tangram/index.html` → 点「开始拼图」→ 点击托盘拼块选中 → 点「旋转」调方向（90° 步进）→ 点击轮廓影子放置（点击影子范围内或距离 < 60px 自动吸附）；放错可拿回重来。**9 关**结算，块数从 2 块递增到 5 块。

**特性**：经典七巧七色（严格标准比例 4:4:2:1:1:2:2）、虚线影子提示、吸附音效、放错拿回无惩罚、横竖屏自适应布局。

### 🔍 找不同小侦探（spot-difference）

左右两幅图（中间竖线隔开）藏着 5 处不同：公园、海底、太空、糖果城、农场、雪地、森林、夜晚、生日、沙漠、海滩、花园、马戏团、超市、恐龙、湖泊、万圣节、游乐园，共 18 大场景！睁大眼睛找出来，找不到了点提示灯泡。

**教育目标**：观察力与专注力（4-8 岁，提示系统教学）

**玩法**：打开 `spot-difference/index.html` → 点「开始侦探之旅」→ 语音介绍场景 → 点击**任意一幅图**的差异处（两图均可点击，放大镜光圈同时在两图上标记）；点错轻摇 + 嗡声不惩罚。找齐 5 处烟花庆祝进下一关，18 关按提示使用数颁奖。

**特性**：18 主题场景（每关色调不同：自然 / 城市生活 / 节日 / 幻想主题全覆盖）、左右分屏 + 中央竖线分隔、差异类型多样（颜色 / 大小 / 有无 / 数量）、提示灯泡闪烁、烟花庆祝。

### ⏰ 时钟小管家（clock-master）

小明 8 点要刷牙、12 点吃午饭、9 点睡觉……听语音把大时钟的时针转到正确的刻度！

**教育目标**：整点、半点与五分钟时刻（5-8 岁，情境化时间概念）

**玩法**：打开 `clock-master/index.html` → 点「开始挑战」→ 听情境提问（如"小明 3 点要玩耍"）→ 点击表盘对应数字刻度（时针缓动转过去）；半点题在「00 分 / 30 分」两个大按钮里选，五分钟题点表盘外圈的分钟刻度（如 2 点 30 分 → 点「30」）。答错指针弹回并报正确时间。14 题结算（整点 4 + 半点 5 + 五分钟 5）。

**特性**：卡通大表盘、情境小场景图标、分针联动、**时针随分钟连续偏移**（2:30 时针指在 2 与 3 正中间、3:50 接近 4 点——与真实钟表完全一致）、答对后指针自动归位到精确钟面、整点 → 半点 → 五分钟渐进、动画播放中重复点击会语音提示而不是静默忽略。

### 🚸 红绿灯过马路（traffic-safety）

小人要纵向过马路（从上路沿走到下路沿，与横向车流垂直交叉）！红灯点了会被汽车喇叭声叫回来，绿灯亮了赶紧点「过马路」沿斑马线穿过车流，往返 8 次通关！

**教育目标**：交通规则与安全意识（3-6 岁，红灯停绿灯行 + 耐心等待）

**玩法**：打开 `traffic-safety/index.html` → 点「去过马路」→ 观察红绿灯（带倒计时数字）→ 绿灯亮时点「过马路」按钮（小人沿中央斑马线纵向迈步、汽车停让）；红灯点了小人半步被制止退回 + 温柔语音提示。绿灯 4 秒犹豫会变红，训练观察与耐心。8 次过街结算，零抢行金牌。

**特性**：白天街景（楼房 / 中央纵向斑马线 / 横向车流，人车方向真实交叉）、红绿灯倒计时、汽车停让动画、无撞人温和设计。

### 🏎️ 极速飞车 3D（racing-3d）

真正的 3D 赛车游戏（非教育向，纯竞速好玩）！基于 three.js 的完整 3D 场景：程序化闭合弯道、低多边形森林、方格旗起跑门。

**玩法**：打开 `racing-3d/index.html` → 点「出发」或按回车 → 3-2-1-GO 大字倒计时后自动踩油门，你只需要 <kbd>←</kbd> <kbd>→</kbd> 左右转向（触屏用屏幕下方按钮）。3 圈竞速，从第 6 名追起，超越 5 辆 AI 对手夺冠军。

**特性**：

- 程序化赛道：椭圆 + 多频正弦扰动的有机闭合弯道，沥青路面 / 红白路肩 / 黄色中线 / 白色车道虚线 / 轮胎磨痕全部程序生成贴图
- 弯道离心力物理：不转向会被甩向路肩，高速过弯必须主动走内线——会玩才能赢
- **道路清晰可读**：路边每 25 米红白条纹距离柱 + 急弯外侧黄色箭头警示牌，弯道走向与车身横向位置一眼可见
- **减速有明示**：冲出赛道时速度表变红 + 弹出"⚠️ 冲出赛道"提示条 + 持续扬尘；贴路肩预警变黄；高速急弯还会甩出漂移烟
- 5 辆 AI 对手：不同极速、切弯走线、避让前车、橡皮筋难度（落后会提速追赶）
- 车辆碰撞：撞车减速 + 侧向弹开 + 屏幕震动
- **性能优化（技能库实战）**：树木与距离柱全部 `InstancedMesh` 实例化（draw call 从 540+ 降到 ~105）、材质缓存复用、尘土粒子合并为单个 `Points` 粒子系统（逐粒子淡出，还修了全场尘土透明度一起跳的 bug）
- **视觉升级**：太阳实时软阴影（PCFSoft + 紧凑 frustum 跟随玩家）、渐变天空穹顶 shader + 地平线热霾亮带、FOV 随速度 64→73 张开 + 过弯相机侧倾、前轮随转向偏摆、菜单/结算界面赛道低空巡航展示镜头
- **朝向修复**：three.js r147 的 `Object3D.lookAt` 让局部 +Z 指向目标，而车模鼻锥建在 -Z——内组翻转 π 修正（此前整车尾灯朝前倒着开）
- 3-2-1-GO 起跑大字 + 对齐的四声倒计时蜂鸣（三短一长）
- 追尾相机（抬高前视，路面视野开阔）、**柔和引擎声**（低通滤波 + 低音量，不吵）、圈数进度点、实时名次 / 速度 / 计时 HUD
- three.js 本地打包（`three.min.js` r147），完全离线可玩

## 通用说明

- **右键已禁用**：全部页面屏蔽鼠标右键 / 触屏板双指误触弹出的系统菜单，游戏不会被意外打断。
- **语音播报防截断**：数字播报（关键教学句）持有全局引用防 GC 回收、同句去重防连点打断，长句不会中途突然没声。
- **主页图标**：仓库首页内置 SVG favicon（星空小火箭），浏览器标签栏直接显示。
- **快捷游戏目录**：主页顶部「🎮 快捷游戏目录」按钮，点击展开全部 20 个教育游戏的图标 + 名称 + 分类标签（数学/语文/思维/生活/综合），点击直接跳转，无需慢慢滚动查找（3D 赛车不在其中）。
- **3D 赛车置底**：主页卡片中极速飞车 3D 始终排在最末尾，教育游戏优先展示。
- **返回主页按钮**：全部 20 个游戏左上角有 🏠 按钮（与原有 HUD 信息条保持 20px 间距），点击弹确认弹窗，防止误触丢失进度。
- **浏览器回退已禁用**：全部页面（含主页）加载即垫哨兵历史记录，按浏览器/手势回退键不会离开游戏，只会弹出与 🏠 相同的确认弹窗；确认返回使用 `location.replace`，主页回退键也不会落回刚离开的游戏页。
- **小火车方向**：列车车头朝左停于右侧，车厢接在车头右侧；每挂一节整列向左挪一格（车尾固定）；挂满先向左开出屏，再调头（车头镜像朝右）开回右侧月台，到站进下一关。
