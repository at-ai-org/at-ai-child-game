# at-ai-child-game

用 AI 编写的少儿教育类小游戏合集，共 **23 个游戏**（22 个教育游戏 + 1 个伪 3D 无尽赛车游戏 `racing-3d`，后者未列入主页快捷目录），外加 1 个成人向的**考研英语复习工具** `mba-english`（主页卡片常驻显示，但未列入快捷目录）。每个页面都是**零依赖的单 HTML 文件**，下载后双击即可在浏览器里离线游玩。

## 游戏

从仓库首页 `index.html` 可以点击进入各个游戏；也可以直接打开各游戏目录下的 HTML 文件。

## 🔈 语音播报不发声？

游戏使用浏览器内置的 Web Speech API 朗读中文。如果只听到音效、听不到语音，按顺序检查：

1. **确认浏览器**：推荐用 **Chrome** 或 **Edge** 打开（联网时会自动使用 Google/微软在线中文语音）。Safari 依赖 macOS 系统语音库。
2. **macOS 安装中文语音**（Safari 必须；系统自带语音更好听）：系统设置 → 辅助功能 → 朗读内容 → 系统声音 → 管理声音 → 中文（简体）→ 下载"婷婷"等语音。
3. **游戏内检查**：点右上角 🔊 确认没有静音（静音时音效和语音一起关闭）。
4. 语音播报的文字内容都会同步显示在**字幕条**上，听不清也能看。

### 🏎️ 数字赛车（number-car）

开着赛车在伪 3D 赛道上飞驰！前方会出现携带数字号码牌的对手车（跑车 / 卡车 / 挖掘机 / 装载机），当对手与你并排时弹出数字输入挑战：

- **答对** → 加速超越对手，获得表扬
- **答错** → 语音播报正确数字并提示重试，直到答对为止（无惩罚，鼓励学习）

**教育目标**：0-9 数字认知、键盘数字键 / 触屏数字键盘练习

**玩法**：
1. 打开 `number-car/index.html`（双击即可，无需服务器）
2. 点击「开始比赛」
3. 对手车接近并排时，输入车尾号码牌上的数字（触屏设备自动显示数字键盘）——**输入即自动提交，无需按回车**
4. 答对超车继续前进，答错会告诉你正确数字，再输一次就行
5. 全程 1000 米，抵达终点获得奖牌（金 18 连对 / 银 12 / 铜 6）

**特性**：
- 伪 3D 透视赛道（OutRun 式投影）：S 形弯道、距离雾化、地平线辉光——速度感强且不刺眼
- 四种尾视图车型：低趴宽体跑车（全宽 LED 尾灯带 + 大尾翼 + 扩散器 + 铬双排气）、厢式卡车（导流罩 + 卷帘门 + 斜纹防撞梁）、挖掘机（履带底盘 + 两段大臂 + 闪爆警示灯）、装载机（人字胎纹 + ROPS 防滚架 + 铲斗连杆），车尾都有醒目的圆形号码牌
- 路边景深装饰：透视分布的松树、护栏柱、带悬垂电线的电线杆
- Web Speech API 中文语音播报：挑战弹出播报"对手的号码是 8，8！"（数字重复两遍），答错时同样重复播报正确数字
- Web Audio 引擎音效与提示音（可静音）
- 答题连击与奖牌结算

### ✈️ 数字飞机（number-plane）

驾驶战机在高空巡航！敌机（战斗机 / 轰炸机 / 直升机）迎面飞来，机身带着大数字。锁定目标后输入它的数字发射导弹：

- **答对** → 导弹沿弧线飞出击毁敌机，**你的战机会变大变强**（战力成长系统）
- **答错** → 语音播报正确数字并提示重试，直到答对为止（无惩罚）

**教育目标**：0-9 数字认知、键盘数字键 / 触屏数字键盘练习

**玩法**：
1. 打开 `number-plane/index.html`（双击即可，无需服务器）
2. 点击「开始任务」
3. 敌机被锁定（出现瞄准框）后，输入它机身号码牌上的数字（触屏设备自动显示数字键盘）——**输入即自动提交，无需按回车**
4. 答对发射导弹击毁敌机，主角战机变大一点（战力 +7%）
5. 击毁 15 架敌机完成任务，按最佳连对颁发金 / 银 / 铜牌

**特性**：
- 三种敌机造型：后掠翼战斗机、双引擎螺旋桨轰炸机、旋翼旋转的直升机
- 导弹抛物线弹道 + 尾烟 + 爆炸冲击环 + 白闪屏震
- 战力成长系统：每击毁一架战机变大（HUD 实时显示战力百分比）
- 旋转虚线锁定框 + 四角括号瞄准动画
- 视差云层 + 星空夜色背景
- Web Speech API 中文语音播报：锁定敌机播报"它身上的数字是 0，0！"（数字重复两遍），答错时同样重复播报
- Web Audio 引擎音效与提示音（可静音）

### 🎈 数字打气球（number-balloon）

彩色气球从夜空缓缓升起，每只都写着大数字。听语音喊出目标数字，把它戳破！

**教育目标**：0-9 数字认知（2-4 岁低幼，点击为主，支持键盘）

**玩法**：打开 `number-balloon/index.html` → 点「开始游戏」→ 听语音（如"戳数字 7！7，7！"，数字重复读）→ 点击写着 7 的气球爆炸得分；点错会告诉你"这是数字 3，找找 7，7 吧"。答对 10 题结算，按最佳连对颁发奖牌。

**特性**：语音字幕条提示、爆炸纸屑粒子、气球飘走自动补发、无惩罚重试、键盘 0-9（含小键盘）直接打气球、回车/空格快速开始或重开。

### 🚂 数字小火车（number-train）

车站月台停着乱序车厢，按 1 → 2 → 3 的顺序点击挂到火车头上，挂满整列呜呜开走——开出屏后还会调头开回月台再进下一站！

**教育目标**：数序概念 1-20（3-6 岁，点击为主，支持键盘）

**玩法**：打开 `number-train/index.html` → 点「发车！」→ 听语音提示先挂几号（如"先挂 1 号，1 号！"，数字重复读）→ 依次点击正确编号车厢（飞到车尾挂上），挂对后播报"接下来挂 5 号，5 号！"；点错车厢会抖动并重复播报要挂的数字。挂满后列车向左开出屏，调头（车头镜像朝右）鸣笛开回右侧月台，到站后进下一关。20 站递增（3 节 → 20 节，第 8 站起出现 10-20 号两位数车厢），通关结算（金 15 连挂 / 银 10 / 铜 5）。

**特性**：白天草原场景、烟囱冒烟粒子、两趟行程（出站 + 调头回站）、开走鸣笛音效、连挂奖牌、键盘直接挂车厢（两位数先按十位再按个位，如 1+5 = 15 号）、回车/空格快速开始或重开、第 20 站 20 节超长列车（两位数车厢用加宽数字牌）。

### 👾 加法小怪兽（math-monster）

毛茸茸的小怪兽肚子饿啦！它说"我要吃 3 个苹果"，就从果树摘 3 个喂它，吃多会吐出来（不生气）。

**教育目标**：数量对应 2-6（3-6 岁，点击计数）

**玩法**：打开 `math-monster/index.html` → 点「开始游戏」→ 听目标数量 → 点击树上的苹果（抛物线飞进嘴里）；头顶气泡显示目标数，肚皮实时显示 n/m；吃满自动封嘴，多点会被温和吐出。8 关结算。

**特性**：大嘴开合动画、打嗝音效、计数气泡、无失败设计。

### 🐿️ 松鼠摘松果（squirrel-pinecone）

松鼠妈妈要囤松果过冬啦！听一听要摘几颗，点一点树上的松果掉进篮子，跟着数 1、2、3……

**教育目标**：按数取物 1-9（3-4 岁，数字 → 数量的逆向映射，基数概念）

**玩法**：打开 `squirrel-pinecone/index.html` → 点「开始摘松果」→ 听语音（如"摘 3 颗松果！3，3！"）→ 依次点击树上的松果，每颗落篮时实时报数；篮中数量徽标实时显示 n/目标。摘多了会提示"只要 3 颗，放回 1 颗"（隐含减法），点篮子放回多余松果；不多不少自动飞进树洞藏好。8 筐通关（数量 1-3 → 4-6 → 7-9 三档递进），结算显示一共帮松鼠藏了多少颗。

**特性**：夜晚森林场景（月亮/远山/篝火色草地）、树上松果微光呼吸提示、落篮抛物线动画、逐颗报数（数到最后一个数 = 总数的基数教学）、摘多放回的温和纠错、树洞藏果计数木牌、松鼠妈妈头顶目标气泡。

### ⚖️ 数字跷跷板（seesaw-compare）

跷跷板两边坐着数字小伙伴！从数小动物比多少，到看点点，再到直接比数字——点对重的一边，跷跷板咣当沉下去！

**教育目标**：比较多少 / 比较大小（3-5 岁，量的比较启蒙）

**玩法**：打开 `seesaw-compare/index.html` → 点「开始游戏」→ 听语音"哪边的小动物多？"→ 点动物更多（或数字更大）的一侧；答对跷跷板向重侧咣当沉下（弹簧动画 + 闷响音效）并播报"5 个比 3 个多！"；答错晃一晃，逐个数给你看。10 题三阶段递进：1-3 题看小动物数多少、4-6 题看点阵、7-10 题直接比数字（含两位数）。

**特性**：夜空星星背景、动物 emoji 队列（8 种随机）、跷跷板支点三角结构 + 板面旋转物理感、答对下沉弹簧动画、点阵模式彩色圆点、纯数字模式大数字牌、连对奖牌。

### 🍦 排队买冰淇淋（icecream-queue）

冰淇淋车前排了长长一队小动物！听清楚：给从前面数第 3 只小动物冰淇淋～

**教育目标**：序数 第 N 个（4-6 岁，序数 vs 基数认知难点）

**玩法**：打开 `icecream-queue/index.html` → 点「开始营业」→ 听语音"给从前面数第三个！给它冰淇淋！"→ 点击对应位置的小动物；答对它蹦跳接过冰淇淋（口味随机）；答错逐个数给看：1、2、3……（序号气泡依次点亮）再试一次。前 4 题从前往后数，之后随机从后往前数。10 单通关（队列 4 → 8 只递增）。

**特性**：
- **冰淇淋车在左侧**、窗口朝着队头，队伍从车右侧往右排——方向和"从前面数"完全一致
- **动物带饱和彩色圆底盘**（6 色轮换 + 白描边 + 深色外圈）：兔子、熊猫、考拉这些浅色 emoji 在奶油背景上也看得清清楚楚
- **窄屏自动折两行**：手机上 8 只动物不重叠，间距/字号/点击热区全部自适应（320px~1280px 实测）
- 队列引导虚线 + 队头箭头，蛇形折行时也能看出"从前往后"的数数方向
- 答错逐个数给看（序号气泡依次点亮 + 数数音效）、口味随机冰淇淋奖励、中文序数词播报（第一个、第二个……）

### 🐸 青蛙跳荷叶（frog-jump）

小青蛙要回家！荷叶上写着数字，听清楚这一关"怎么数"，点到对的那片荷叶。

**教育目标**：数序与数感启蒙（3-6 岁，数数 0-20：顺序 / 倒数 / 跳数）

**玩法**：打开 `frog-jump/index.html` → 点「开始跳荷叶」→ 听语音"第 1 关，按顺序数 0 到 5！从 0 开始，下一片是 1！"→ 点击写着正确数字的荷叶；跳对青蛙蹦过去并报出数字，点错则扑通落水（水花 + 波纹动画），语音提示"要跳 2 哦！1 的后面是 2，2！"。每关跳满 **5 片荷叶** 即到对岸过关。

**9 关设计**（每关 6 片荷叶 + 3 片干扰荷叶，需跳 5 片）：

| 关 | 玩法 | 数字路径 |
|---|---|---|
| 1 | 按顺序数 | 0 → 1 → 2 → 3 → 4 → 5 |
| 2 | 接着数（从上一关终点继续） | 5 → 6 → 7 → 8 → 9 → 10 |
| 3 | 接着数 | 10 → 11 → 12 → 13 → 14 → 15 |
| 4 | 接着数 | 15 → 16 → 17 → 18 → 19 → 20 |
| 5 | 倒着数 | 20 → 19 → 18 → 17 → 16 → 15 |
| 6 | 两个两个数 | 0 → 2 → 4 → 6 → 8 → 10 |
| 7 | 倒着两个两个数 | 10 → 8 → 6 → 4 → 2 → 0 |
| 8 | 四个四个数 | 0 → 4 → 8 → 12 → 16 → 20 |
| 9 | 倒着四个四个数 | 20 → 16 → 12 → 8 → 4 → 0 |

前 4 关连着数完 0-20（**下一关从上一关结束的荷叶继续**，数字无缝衔接），后 5 关在同一数域内换玩法练数感。

**特性**：完整青蛙造型（后腿蹬水 + 前腿撑地 + 三趾脚蹼，跳跃时蹬腿伸展、张嘴弹跳）、池塘水面波光粼粼、荷叶 V 形缺口 + 叶脉、干扰荷叶上下错位布置（相邻数 / 差半步 / 差整步的陷阱）、下一片目标金色光环呼吸提示、跳跃抛物线 + 落地涟漪、HUD 显示本关数字区间与荷叶进度、报数音高递增。

### 📖 汉字闯关（hanzi-quest）

听语音读字，从四个选项里把它找出来！一共 9 关、99 个常用汉字，是仓库里字量最大的识字游戏。

**教育目标**：常用汉字认读 99 字（4-8 岁，9 大主题分类递进）

**玩法**：打开 `hanzi-quest/index.html` → 点「开始闯关」→ 听语音读字（读两遍更清晰）→ 在四个候选汉字卡片里点出正确的那张；点题干卡片可**再听一次**，键盘 <kbd>1</kbd>-<kbd>4</kbd> 也能选，按 <kbd>R</kbd> 重听。答对撒粒子庆祝，答错会温和播报正确读音（无惩罚，可重选）。9 关全部完成学会 99 字。

**图形提示**（右上角开关，**默认开启**）：
每个汉字下面都画了一个对应的**形象物体**，让孩子「看图形 → 记字形」，图文一起进脑子。

- **手势数字**：**九** = 手势 9（🤙 伸直拇指和小指）、**十** = 手势 10（👍 竖起大拇指），图下方直接用大字写出 **9 / 10**，孩子跟着比手指就能记住
- **象形图画**（照着汉字自己的样子画，图和字长得像，一看就能对上）：一 一根小棍子 / 二 两根 / 三 三根、**四** 四面围起来的田字窗、**目** 竖写的一只眼睛、**耳** 一只耳朵（含耳廓与耳道）、**口** 张得大大的嘴巴（嘴唇 + 牙齿 + 舌头）、**山** 三座连着的山峰、**门** 一扇木门、**看** 两只亮晶晶的眼睛、**说** 一张正在说话的嘴巴、**多** 一堆圆点 / **少** 孤零零一个点
- **实物 / 场景画**：**天** 蓝天 + 太阳 + 白云 + 飞鸟、手→✋、心→❤️、水→💧、火→🔥、鸟→🐦、鱼→🐟、家→🏠、车→🚗、星→⭐ 等（矢量画不出来的一律用 emoji，色彩饱满、一眼认得出）
- **颜色字**直接给色块：红/黄/白/黑
- 开启时**题干卡片右上角**也显示目标字的图（听到「耳」同时看到耳朵，双通道记忆）；答对后语音会补一句图纸讲解（如「耳，软软的一只耳朵」）
- 点右上角开关可切换「图形提示 / 纯文字」两种模式，选择记在 localStorage 里，下次打开沿用

弯道不旋转相机，而是把路面按段横向累积平移，画面自然「甩」向一边，这就是伪 3D 的灵魂。
好处是完全不依赖 WebGL、任何浏览器都能跑，实测 1280×800 下满速行驶稳定 60fps。

（<kbd>↑</kbd>/<kbd>W</kbd> 可补一脚更快的加速，<kbd>↓</kbd>/<kbd>S</kbd> 刹车；触屏用屏幕下方按钮）。
**超车必须靠左右走线**：前方的对手会守着自己的车道，直接怼上去会撞车（减速 + 震屏），
只有变道绕过去才算「超越」。**这条路没有终点**，左上角记录你的**里程（km）**、**超越车辆数**、
**「中华大地已走 N 圈」**（每跑满 34 个省份 = 34 公里记 1 圈），
以及**「当前处于 X 省」**——左侧每 1 公里立一块地区指示牌，
依次报出中国的 34 个省级行政区（含港澳台），HUD 会随牌子切换显示当前所在地。

**道路与场景（历次优化汇总）**：

- **道路抖动（第三轮，彻底修好）**：前两轮各修了一半。根源是**弯道值 `curve`
  的采样方式**：`x`（路面横向位置）是 `curve` 的累加，而累加起点每帧都从
  当前段 `baseIdx` 重新开始 —— 于是「同一个世界位置」在跨段前后被算成不同的 `x`。
  实测每跨一次段边界，路面横坐标仍会跳 **0.09~0.27px**，且方向左右交替，
  满速每秒 **22.7 次**，这就是肉眼看到的抖动。
  现在把 `curve` 定义为**绝对世界坐标的函数**（按边界的绝对段坐标取相邻两段插值，
  不再使用全局 `bp` 相位），同一世界位置永远得到同一个值。
  实测路面的横向突跳由 **0.687px → 0.0004px（改善约 1600×）**；
  连续帧的移动方向能一致保持 10~15 帧，是平滑运动而非抖动
- **路面不再有「马路线」条纹**：原来路面按段号奇偶交替铺两种灰、
  草地也交替明暗、雨天积水还是每隔一段画一条亮条。满速时每秒跨过 22.7 个路段，
  这些交替图案以 **11.4 Hz** 闪烁，看起来就是一条条横向「斑马线」扑面而来。
  现在路面/草地/积水全部改成单一底色（层次改由**纵向**的车辙、内带/外带表现），
  路缘红白条也从「每段交替」放慢到「每 3 段交替」（≈4Hz），像真实赛道路缘石
- **大雨天不再有「高低台阶」**：两个原因。
  ① 地面高度 `hillAt` 用的是**线性插值** —— 高度连续但**斜率不连续**，
  每个段边界都留一个折角（实测左右导数差 1.0e-1）；平时路面哑光看不出来，
  但**大雨时路面有水膜高光**，折角处的明暗变化被放大成一道道台阶。
  改用 **Catmull-Rom 样条**（C1 连续）后折角降到 4.0e-3（**改善 25×**，
  多数边界达 10⁴×）。② 坡道振幅 `HILL_AMP` 由 420 降到 260，近处起伏平缓约 38%
- **道路加宽 + 改成单向三车道**：`KS` 由 `0.110` 提到 `0.150`，玩家处路面全宽
  **350px → 478px**（占屏 34% → 47%），路面明显更宽阔；标线同步改成三车道
  （两条白色虚线分隔三条车道 + 两侧白边线），车辙也铺到三条车道中心
- **AI 不再「全挤在一起」（第二轮，找到真正的根因）**：除了车道分配，还有两个更深的原因 ——
  ① **所有 AI 的速度曾被写死成同一个常数**：目标速度那行写成
  `MAX_SPEED * (0.62 + rnd(...) * 0.0 + 0.10)`，随机项被乘了 `0.0`，
  于是 `want ≡ 0.72×极速`。**同速车永远不会自然分开** ——
  实测 30 秒后 8 辆车速度全是 3600、全挤在 340~2000 单位内。
  现在每辆车有自己的巡航速度（`cruise` 0.62~0.90），车流有快慢才会散开。
  ② **AI 之间没有保持车距**：现在同车道跟车太近就松油门（`KEEP_GAP`），
  车流自然拉成一列列。实测「同车道车距小于一个车身」的比例由 **10% 降到 0.09%**，
  中位车距 **18045** 单位；玩家附近叠车 **0** 次
- **修「别的车开起来一前一后顿挫」（第三轮，找到真正的根因）**：
  前两轮修的是「拉扯」（幅度太大），但**顿挫**的根因是**目标速度不连续**。
  排查中发现三处**阶跃**：
  ① 橡皮筋是三条 `if` 台阶（`gap>12000 → ×1.15`、`gap>6000 → ×1.06`、
  `gap<-3000 → ×0.92`），车距在阈值附近来回时目标速度在两个差 9% 的值之间反复跳；
  ② 防扎堆里 `if (dz < HIT_DZ*2.2) want = min(want, o.speed*0.88)` —— 一次硬跳变；
  ③ 上一轮加的 `AI_ACCEL_MAX` 限幅**本身就是顿挫源**：
  它把速度变成一条斜坡，而斜坡跟不上连续变化的目标 ——
  速度永远落后一点、再猛追、再落后，表现为持续抖动。
  **修法**：把三处全部换成连续函数（橡皮筋改 tanh 平滑曲线、
  防扎堆改 `follow = 1 - 0.18*t` 线性连续）、**删掉限幅**改用一阶惯性跟踪
  （`AI_FOLLOW_RATE = 2.5`，加减速对称）。
  目标连续 → 一阶惯性输出必然连续。
  实测「加速度反复变向」次数由 **152 次 / 180 秒 降到 6~10 次**（约 20 倍改善），
  剩余的是正常跟车调整；同车道车距中位数反而升到 **31869**，
  「小于一个车身」的比例 **0.00%**

  **350px → 478px**（占屏 34% → 47%），路面明显更宽阔；标线同步改成三车道

  而路面全宽是 2.0 倍路宽 —— 所以河**比路面宽一倍**（原先与路面等宽，按要求加宽了一倍）。
  分三层画：河岸（泥土色）→ 水面（深青蓝）→ 靠岸的天光高光条，
  三层位置都按河道宽度取比例，改 `RIV_OUT` 时自动适配；
  冬天自动结冰发白；因为用的是与路面/车道/护栏**同一个 GEO 投影表**，
  弯道时河道会跟着路面一起摆 —— 就是「沿着公路流」。
  同时把左侧景物挡在河外：左侧林线要么在河边以内（<3.2）要么挪到河对岸（>7.4）
  —— 实测左侧河道内房屋 0、鱼塘 0、树 0，没有东西浮在水上
- **路边景层次**：草地分「路肩草 → 田野」两条不同明度的带；路边物件扩到
  树 / 灌木 / 石头 / 小花 / 弯道警示牌 / 电线杆 / 远处农舍 / 鱼塘 / 跨路龙门架，
  并有「近景带密、远景带疏」的林线，路两侧不再是空绿一片
- **性能护栏**：物件绘制做了距离与尺寸双重剔除（远景只保留房子 / 龙门架 / 大林线）。
  实测对比：物件画到 0.70 倍可视距离 → 52fps（14.7ms/帧）；0.50 倍 → 60fps（12.1ms/帧），
  远处 1~2px 的物件肉眼几乎看不出差别，取 0.50 优先保帧率
- **自动回正**：原来只有离心力、没有任何回正机制，完全不操作方向时车会单向漂移
  （实测 8 秒从 0 漂到 −0.52，之后一直贴着 ±1.6 边界压在草地上）。
  现在松开方向盘会缓慢把车拉回路中央，高速回正更弱、偏离越大拉得越强，
  既不跟玩家抢方向，也让「自动油门 + 只管左右转」的玩法真正成立
- **修复发车后车速恒为 0**：README 与开始界面一直写着「油门自动」，但代码只有按住 <kbd>↑</kbd> 才会加速，
  导致发车后 e.g. 车速停在 0 km/h、里程永远是 0.00。现已改为真正的自动给油，
  <kbd>↓</kbd> 刹车松手后自动恢复巡航

**特性**：

- **无尽模式，永远开不到头**：没有圈数、没有终点、没有结算界面，想开多久开多久
- **无限公路实时生成**：中心线由「有界噪声」按弧长实时求出（`位置 = f(行驶距离)`），前方永远有新的弯道冒出来，身后 300m 自动冻结不再改写；几何顶点数固定（1000 个），**开 50 万米内存也不增长**
- **四季轮转**（每季 75 秒，春→夏→秋→冬往复）：
  - 🌸 春天：嫩绿草地 + 满路小花
  - 🌿 夏天：深绿浓荫 + 强烈日照
  - 🍁 秋天：金黄落叶地面 + 橙红树冠 + 大风偏多
  - ❄️ 冬天：雪地 + 灰白树木 + 日照减弱 + 常下雪起雾
- **七种天气轮着来**（每种持续 20~34 秒，按季节加权，如夏天雷雨多、冬天下雪多）：
  - ☀️ 晴朗 / ☁️ 阴云 / 💨 大风 / 🌫️ 浓雾 / 🌧️ 大雨 / ⛈️ 雷雨 / 🌨️ 飞雪
  - **雨天**：340 颗雨滴粒子 + 路面水膜反光 + 积水镜面 + 打滑（抓地力降到 0.8，车会轻微侧滑）
  - **雷雨**：闪电频闪整屏加亮 + 天空压暗 + 延迟滚动的**雷声**
  - **下雪**：220 片雪花飘落 + 路面积雪与路肩堆雪 + 抓地力降到 0.7（最容易打滑）
  - **浓雾**：雾浓度拉到最高，路面在雾里消失
  - **大风**：侧风持续横推车身，需要反打方向
- **左上角极简 HUD**：只有 🛣️ 里程（km）和 🚗 超越车辆数（超车时数字弹跳 + 音效）
- **超车判定严谨**：只统计"真的从它后面超到它前面"，远处的车自己开走、或者被反超后再超回来，都算得准（不会误计数）
- **无限车流**：场上固定 8 辆 AI，被超越的会加速开走并淡出，前方随即补一辆新车——**永远有车可超**
- 弯道离心力物理 + **自然回正**：过弯会被甩向路肩，需要主动走线；但松开方向会缓慢回正，不会一直贴在草地上
- **道路清晰可读**：单向三车道标线（两条白虚线 + 两侧白边线）+ 车辙 + 路边红白条纹距离柱 + 急弯外侧黄色箭头警示牌 + 跨路龙门架
- **冲出公路有明示**：里程卡片变红 + 弹出"⚠️ 冲出公路"提示条 + 画面泛红
- **性能优化**：全场几何算在一张 `GEO` 投影表里（路面 / 标线 / 护栏 / 路边物件 / AI 车全读同一份数据），
  段高 < 1px 早退、物件按距离与尺寸双重剔除；实测 1280×800 满速 60fps
- **视觉**：速度感 FOV（62° 随速度张开）、高速四周压暗 + 速度线、远山双层视差、云层随天气变密变暗、太阳光晕
- 倒计时起跑音 + 柔和引擎声（低通滤波 + 低音量，不吵）+ 雨声风声环境音
- **零依赖单文件**：纯 2D Canvas 伪 3D，不加载 three.js，完全离线可玩

### 📖 新探索英语复习（mba-english）

《新探索研究生英语读写教程（提高版）》**Unit 1–5** 的复习工具（非少儿向，成年人考研英语复习用，主页卡片常驻显示但未列入快捷目录）。

**内容规模**：核心词汇 **236** 个、专有名词 **31** 个、难句解析 **27** 句——全部由 `新探索英语.txt` 解析生成到 `data.js`，单词、词性、释义、原文、翻译、语法解析与原文逐条一致。

**玩法**：打开 `mba-english/index.html` → 选复习方式 → 选单元（可多选，不选＝全部 Unit 1–5）→ 开始复习。

**9 种复习模式**：

| 模式 | 练什么 |
| --- | --- |
| 🃏 单词抽认卡 | 看英文猜中文，翻面看释义；「记住了 / 再复习」（再复习的卡片会自动插回队列） |
| 🔤 英译中选择题 | 词 → 4 个中文释义选 1 |
| 🀄 中译英选择题 | 释义 → 4 个英文单词选 1 |
| ⌨️ 拼写闯关 | 看释义和词性拼出英文，可逐字母提示（自动剔除短语与超短词） |
| 🧩 词义辨析 | 干扰项**限定同一单元**的近义/同类词，练精确区分 |
| 🏛️ 专有名词 | 机构、地名、人名、书名中英对照；优先同单元干扰项 |
| 🎯 难句选句 | 给中文译文，从 4 个英文原句中选对应的那句 |
| 🧠 语法点解读 | 读原句 + 译文，判断哪条语法解析是对的 |
| ✏️ 难句填空 | 自动从原句挖出核心词汇或短语（挖空点优先命中本单元词表），配合译文填回 |

- 数据全部内联为 `data.js` + 单 HTML，**零依赖、离线可用**，双击即可打开

### 🎹 电子琴（keyboard-piano）

用电脑键盘弹琴！不需要任何外接设备，打开就能演奏。

**教育目标**：音乐启蒙、音高感知、手眼协调（5 岁以上，也适合大人随手弹）

**键盘分两区（遵循电脑键盘的通用布局逻辑）**：

- **左区 · 26 个字母键 = 白键（自然音 do re mi fa sol la si）**
  按物理键盘三排排列：<kbd>Q W E R T Y U I O P</kbd> 在上、<kbd>A S D F G H J K L</kbd> 居中、<kbd>Z X C V B N M</kbd> 在下，与真实键盘位置一致。26 个白键从 C3 到 G6，覆盖约 3.7 个八度。
- **右区 · 9 个数字键 = 黑键（升降音 C# D# F# G# A#）**
  <kbd>1</kbd>-<kbd>9</kbd> 从低到高排列，竖排在右侧。

**玩法**：按住键盘上的字母/数字键即可发声（支持同时按多个键弹和弦），也可以用鼠标/手指点击琴键。每次敲击时，**琴键上方会飘出键位大字和对应音符**（如 `Q` + `C3 · do`）。右侧面板按顺序记录本次按下的所有键位。

**特性**：

- **按键顺序记录**：实时记录本次全部按键的键位与音符，超过 20 个只展示最近 20 个（完整记录保留在内存中）
- **一键复制**：点击「📄 复制全部键位」复制**本次全部**按键记录（格式：键位行 + 音符行，便于分享乐谱动机）；快捷键 <kbd>Ctrl/Cmd</kbd>+<kbd>C</kbd> 也可复制
- 三种音色（钢琴 / 风琴 / 合成器）+ 三档音量，Web Audio 实时合成（多振荡器 + ADSR 包络 + 低通滤波，柔和耐听）
- 琴键按下有高亮光效 + 飘字动画；白键/黑键视觉区分明确
- 「键名显示」开关可隐藏琴键上的音名，适合当"盲弹"练习
- 失焦自动松开全部按键，不会卡音

- **右键已禁用**：全部页面屏蔽鼠标右键 / 触屏板双指误触弹出的系统菜单，游戏不会被意外打断。
