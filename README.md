# at-ai-child-game

用 AI 编写的少儿教育类小游戏合集。每个游戏都是**零依赖的单 HTML 文件**，下载后双击即可在浏览器中离线游玩。

## 游戏

从仓库首页 `index.html` 可以点击进入各个游戏；也可以直接打开各游戏目录下的 HTML 文件。

### 🏎️ 数字赛车（number-car）

开着赛车在伪 3D 赛道上飞驰！前方会出现携带数字号码牌的对手车（跑车 / 卡车 / 挖掘机 / 装载机），当对手与你并排时弹出数字输入挑战：

- **答对** → 加速超越对手，获得表扬
- **答错** → 语音播报正确数字并提示重试，直到答对为止（无惩罚，鼓励学习）

**教育目标**：0-9 数字认知、键盘数字键 / 触屏数字键盘练习

**玩法**：
1. 打开 `number-car/index.html`（双击即可，无需服务器）
2. 点击「开始比赛」
3. 对手车接近并排时，输入车尾号码牌上的数字（触屏设备自动显示数字键盘）——**输入即自动提交，无需按回车**
4. 答对超车继续前进，答错会告诉你正确数字，再输一次就行
5. 全程 1000 米，抵达终点获得奖牌（金 18 连对 / 银 12 / 铜 6）

**特性**：
- 伪 3D 透视赛道（OutRun 式投影）：S 形弯道、距离雾化、地平线辉光——速度感强且不刺眼
- 四种尾视图车型：跑车、卡车、挖掘机、装载机，车尾都有醒目的圆形号码牌
- 路边景深装饰：透视分布的松树、护栏柱、带悬垂电线的电线杆
- Web Speech API 中文语音播报（答错时朗读正确数字）
- Web Audio 引擎音效与提示音（可静音）
- 答题连击与奖牌结算

### ✈️ 数字飞机（number-plane）

驾驶战机在高空巡航！敌机（战斗机 / 轰炸机 / 直升机）迎面飞来，机身带着大数字。锁定目标后输入它的数字发射导弹：

- **答对** → 导弹沿弧线飞出击毁敌机，**你的战机会变大变强**（战力成长系统）
- **答错** → 语音播报正确数字并提示重试，直到答对为止（无惩罚）

**教育目标**：0-9 数字认知、键盘数字键 / 触屏数字键盘练习

**玩法**：
1. 打开 `number-plane/index.html`（双击即可，无需服务器）
2. 点击「开始任务」
3. 敌机被锁定（出现瞄准框）后，输入它机身号码牌上的数字（触屏设备自动显示数字键盘）——**输入即自动提交，无需按回车**
4. 答对发射导弹击毁敌机，主角战机变大一点（战力 +7%）
5. 击毁 15 架敌机完成任务，按最佳连对颁发金 / 银 / 铜牌

**特性**：
- 三种敌机造型：后掠翼战斗机、双引擎螺旋桨轰炸机、旋翼旋转的直升机
- 导弹抛物线弹道 + 尾烟 + 爆炸冲击环 + 白闪屏震
- 战力成长系统：每击毁一架战机变大（HUD 实时显示战力百分比）
- 旋转虚线锁定框 + 四角括号瞄准动画
- 视差云层 + 星空夜色背景
- Web Speech API 中文语音播报（答错时朗读正确数字）
- Web Audio 引擎音效与提示音（可静音）

### 🎈 数字打气球（number-balloon）

彩色气球从夜空缓缓升起，每只都写着大数字。听语音喊出目标数字，把它戳破！

**教育目标**：0-9 数字认知（2-4 岁低幼，点击为主，支持键盘）

**玩法**：打开 `number-balloon/index.html` → 点「开始游戏」→ 听语音（如"戳数字 7！"）→ 点击写着 7 的气球爆炸得分；点错会告诉你"这是数字 3，找找 7 吧"。答对 10 题结算，按最佳连对颁发奖牌。

**特性**：语音字幕条提示、爆炸纸屑粒子、气球飘走自动补发、无惩罚重试、键盘 0-9（含小键盘）直接打气球、回车/空格快速开始或重开。

### 🚂 数字小火车（number-train）

车站月台停着乱序车厢，按 1 → 2 → 3 的顺序点击挂到火车头上，挂满整列呜呜开走！

**教育目标**：数序概念 1-8（3-5 岁，点击为主，支持键盘）

**玩法**：打开 `number-train/index.html` → 点「发车！」→ 听语音提示先挂几号 → 依次点击正确编号车厢（飞到车尾挂上）；点错车厢会抖动并播报"这是 4 号车厢，现在要挂 2 号哦"。8 站递增（3 节 → 8 节），通关结算。

**特性**：白天草原场景、烟囱冒烟粒子、开走鸣笛音效、连挂奖牌、键盘 1-8（含小键盘）直接挂车厢、回车/空格快速开始或重开。

### 👾 加法小怪兽（math-monster）

毛茸茸的小怪兽肚子饿啦！它说"我要吃 3 个苹果"，就从果树摘 3 个喂它，吃多会吐出来（不生气）。

**教育目标**：数量对应 2-6（3-6 岁，点击计数）

**玩法**：打开 `math-monster/index.html` → 点「开始游戏」→ 听目标数量 → 点击树上的苹果（抛物线飞进嘴里）；头顶气泡显示目标数，肚皮实时显示 n/m；吃满自动封嘴，多点会被温和吐出。8 关结算。

**特性**：大嘴开合动画、打嗝音效、计数气泡、无失败设计。

### 🎣 数字钓鱼（number-fishing）

夜晚池塘，鱼儿叼着算式牌游动。看好目标答案（如"= 5"），钓起叼着"2+3"的那条鱼！

**教育目标**：10 以内口算加减（5-8 岁，难度递增 5→10→20 以内）

**玩法**：打开 `number-fishing/index.html` → 点「开始钓鱼」→ 看顶部目标答案 → 点击叼着正确算式的鱼（甩线钓起）；点错鱼会下沉并播报"3+1 等于 4，不是 5 哦"。答 12 题结算。

**特性**：夜色池塘波光、月亮倒影、三种鱼造型、难度随进度升级。

### 🚁 汉字直升机（hanzi-helicopter）

驾驶直升机巡航蓝天！敌机贴着汉字圆牌飞来，听语音提示从四个候选字里点出正确的，发射导弹击落！

**教育目标**：汉字启蒙 30 字（4-7 岁，3 级字库：数字人体 → 自然 → 方位形容）

**玩法**：打开 `hanzi-helicopter/index.html` → 点「开始任务」→ 锁定敌机后弹窗显示大目标字 + 拼音 + 4 个候选汉字按钮 → 点选正确字击毁敌机；点错播报正确字读音。每级 10 架共 30 架，识字进度条飞满通关。

**特性**：导弹弹道爆炸、识字进度条、形近字干扰候选、无惩罚重试。

### 🌧️ 拼音气球雨（pinyin-rain）

声母韵母组合的气球从天上飘落。听语音念出目标词（如"爸爸的爸"），点中正确音节的气球爆出汉字！

**教育目标**：拼音音节组合（5-7 岁，b-a→爸）

**玩法**：打开 `pinyin-rain/index.html` → 点「开始游戏」→ 听目标词 → 点击正确拼音组合的气球（爆炸显示对应汉字）；点错播报正确音节。答 12 题结算。

**特性**：雨天夜景、爆炸出字动画、词库 16 字、语音 + 字幕同步。

### 🐠 颜色捕鱼（color-fishing）

明亮小池塘游着红黄蓝绿橙紫六种颜色的鱼。听语音"抓一条红色的鱼"，点中放进渔桶！

**教育目标**：颜色认知 6 色（2-4 岁低幼，纯语音 + 点击，鱼身无文字）

**玩法**：打开 `color-fishing/index.html` → 点「开始捕鱼」→ 听颜色名 → 点击对应颜色的鱼（飞入侧边渔桶 + 水花）；点错播报"这是黄色，找红色的鱼"。12 题结算。

**特性**：亮色池塘白天场景、渔桶计数、六色三形鱼、低幼大热区。

### 🍪 形状饼干工厂（shape-biscuit）

饼干工厂开工啦！传送带送来圆形、三角形、正方形、五角星、心形饼干，听语音用对应模具盖章！

**教育目标**：形状认知 5 种（2-4 岁低幼，点击模具）

**玩法**：打开 `shape-biscuit/index.html` → 点「开始烤饼干」→ 听"给三角形饼干盖章！"→ 点击底部对应模具（饼干烤成金色飘香）；盖错模具饼干溜走并播报形状名。烤好 15 块结算。

**特性**：温暖面包房色调、传送带滚动、盖章动画、香气粒子。

### 🃏 记忆翻牌（memory-cards）

16 张图案卡片扣着放：小猫、小狗、星星、月亮……一次翻两张，配对成功会念出图案名字！

**教育目标**：短时记忆与配对（3-6 岁，图案名朗读扩展词汇）

**玩法**：打开 `memory-cards/index.html` → 点「开始游戏」→ 点击卡片翻开 → 再点一张：一样配对成功（亮起 + 朗读名字），不一样 1 秒后翻回。3 关递增（4 对 → 6 对 → 8 对），按翻牌效率颁奖牌。

**特性**：翻转动画、16 种纯 Canvas 图案、配对烟花粒子、无时间压力。

### 🧩 七巧板（tangram）

七块彩色拼板拼出小猫、房子、小船、火箭！点选拼板、旋转方向、放到轮廓影子附近自动吸附。

**教育目标**：图形空间拼组（4-8 岁，旋转 + 吸附操作）

**玩法**：打开 `tangram/index.html` → 点「开始拼图」→ 点击托盘拼块选中 → 点「旋转」调方向（90° 步进）→ 点击轮廓影子附近放置（距离 < 30px 自动吸附）；放错可拿回重来。4 关结算。

**特性**：经典七巧七色、虚线影子提示、吸附音效、放错拿回无惩罚。

### 🔍 找不同小侦探（spot-difference）

上下两幅图藏着 5 处不同：公园、海底、太空、糖果城！睁大眼睛找出来，找不到了点提示灯泡。

**教育目标**：观察力与专注力（4-8 岁，提示系统教学）

**玩法**：打开 `spot-difference/index.html` → 点「开始侦探」→ 语音介绍场景 → 点击下图的差异处（放大镜光圈标记）；点错轻摇 + 嗡声不惩罚。找齐 5 处烟花庆祝进下一关，4 关按提示使用数颁奖。

**特性**：4 主题场景（每关色调不同）、差异类型多样（颜色 / 大小 / 有无 / 数量）、提示灯泡闪烁、烟花庆祝。

### ⏰ 时钟小管家（clock-master）

小明 8 点要刷牙、12 点吃午饭、9 点睡觉……听语音把大时钟的时针转到正确的刻度！

**教育目标**：整点与半点（5-8 岁，情境化时间概念）

**玩法**：打开 `clock-master/index.html` → 点「开始挑战」→ 听情境提问（如"小明 3 点要玩耍"）→ 点击表盘对应数字刻度（时针缓动转过去）；半点题先点小时，再在两个大按钮里选 00 分 / 30 分。答错指针弹回并报正确时间。12 题结算。

**特性**：卡通大表盘、情境小场景图标、分针联动、整点 → 半点渐进。

### 🚸 红绿灯过马路（traffic-safety）

小人要过马路！红灯点了会被汽车喇叭声叫回来，绿灯亮了赶紧点「过马路」走斑马线，往返 8 次通关！

**教育目标**：交通规则与安全意识（3-6 岁，红灯停绿灯行 + 耐心等待）

**玩法**：打开 `traffic-safety/index.html` → 点「去过马路」→ 观察红绿灯（带倒计时数字）→ 绿灯亮时点「过马路」按钮（小人迈步、汽车停让）；红灯点了小人半步被制止退回 + 温柔语音提示。绿灯 4 秒犹豫会变红，训练观察与耐心。8 次过街结算，零抢行金牌。

**特性**：白天街景（楼房 / 斑马线 / 车流）、红绿灯倒计时、汽车停让动画、无撞人温和设计。
